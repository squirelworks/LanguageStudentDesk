# LanguageStudentDesk

A collection of language learning tools and environments.

## Tools

- [Klingon (tlhIngan Hol)](klingon/) — Focuses on the pIqaD script with interactive lessons and quizzes.
- [Character Learner](character-learner/) — Modular TenguGo-style trainer for Arabic, Cyrillic, Hangul, Devanagari, Japanese kana, and a kanji stub (JLPT + on-yomi).

More languages and tools coming soon.
