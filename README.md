# SquirrelGo Orthodox Bible text packs

Generated by the "SquirrelGo Orthodox Bible text packs" workflow from
SquirrelGo-Apps/squirrelgo-orthodox-bible/tools/texts on the main branch.
Each bibles/<id>.js is a public-domain or openly licensed Bible and each
commentary/<id>.js a Father's commentary; its
license and source are in the file's first lines and in tools/texts/README.md.
This branch is force-pushed on every build; do not commit to it.
