# Archived Klingon WebView shell

This is the old Android WebView project for SquirrelGo Klingon. Nothing builds it.
The app that ships is the native one, package `com.squirelworks.squirrelgoklingon`,
and the release file is `SquirrelGoKlingon.apk`, signed with the committed debug key.

The lessons, stroke files, recordings, fonts and the browser page stayed in
`SquirrelGo-Apps/squirrelgo-characters/squirrelgo-klingon/`. The native build
reads those files.
