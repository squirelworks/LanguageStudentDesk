# Archived Orthodox Bible WebView shell

This is the old Android WebView project for SquirrelGo Orthodox Bible. Nothing builds it.
The app that ships is the native one, package `com.squirelworks.squirrelgoorthodoxbible`,
and the release file is `SquirrelGoOrthodoxBible.apk`, signed with the committed debug key.

The texts, commentary and the browser page stayed in
`SquirrelGo-Apps/squirrelgo-orthodox-bible/`. The native build reads those files.
Downloadable packs stay on the `orthodox-bible-packs` release.
