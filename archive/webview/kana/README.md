# Archived Kana WebView shell

This is the old Android WebView project for SquirrelGo Kana. Nothing builds it.
The app that ships is the native one, package `com.squirelworks.squirrelgokana`,
and the release file is still `SquirrelGoKana.apk`.

The lessons, stroke files, recordings and the browser page stayed in
`SquirrelGo-Apps/squirrelgo-characters/squirrelgo-kana/`. The native build and
the Desk learners read those files, and the shared scripts in `www/js/` are
copies of `SquirrelGo-Apps/shared/` that the other apps still sync.
