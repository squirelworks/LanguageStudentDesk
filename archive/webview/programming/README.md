# Archived Programming Student Desk WebView shell

This is the old Android WebView project for Programming Student Desk. Nothing builds it.
The app that ships is the native one, package `com.squirelworks.programmingstudentdesk`,
and the release file is `ProgrammingStudentDesk.apk`, signed with the committed debug key.

The menu, the Programming Learner pages and the shared language files stayed where they were.
The native build reads those files.
