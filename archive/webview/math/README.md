# Archived Maths Edu-Training Helper WebView shell

This is the old Android WebView project for Maths Edu-Training Helper. Nothing builds it.
The app that ships is the native one, package `com.squirelworks.mathseducationtraininghelper`,
and the release file is `MathsEduTrainingHelper.apk`, signed with the committed debug key.
The name stays Maths Edu-Training Helper.

The menu, the Math Learner pages and the shared language files stayed where they were.
The native build reads those files. The Play listing pack stayed with this project,
at `app/src/main/play/`.
