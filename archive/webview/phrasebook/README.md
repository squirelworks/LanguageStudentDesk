# Archived Phrasebook WebView shell

This is the old Android WebView project for SquirrelGo Phrasebook. Nothing builds it.
The app that ships is the native one, package `com.squirelworks.squirrelgophrasebook`,
and the release file is `SquirrelGoPhrasebook.apk`, signed with the committed debug key.

The packs, recordings and the browser page stayed in
`SquirrelGo-Apps/squirrelgo-phrasebook/`. The native build reads those files.
