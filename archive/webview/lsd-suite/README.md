# Archived Language Student Desk WebView shell

This is the old Android WebView project for Language Student Desk. Nothing builds it.
The app that ships is the native one, package `com.squirelworks.lsd`,
and the release file is `LanguageStudentDesk.apk`, signed with the committed debug key.

The suite menu, the learner pages and `suite.js` stayed where they were.
The native build reads those files.
