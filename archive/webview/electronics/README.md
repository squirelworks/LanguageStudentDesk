# Archived Electronics Student Desk WebView shell

This is the old Android WebView project for Electronics Student Desk. Nothing builds it.
The app that ships is the native one, package `com.squirelworks.electronicsstudentdesk`,
and the release file is `ElectronicsStudentDesk.apk`, signed with the committed debug key.

The menu, the Electronics Learner pages and the shared language files stayed where they were.
The native build reads those files. The Play listing pack stayed with this project,
at `app/src/main/play/`.
