QuickBASIC

Microsoft’s structured BASIC for DOS (late 1980s–early 1990s). Line numbers optional, procedures with SUB/FUNCTION, and a full IDE.

Key ideas

  • Variables, INPUT, PRINT
  • Control flow: IF…THEN, FOR…NEXT, WHILE
  • Subs and functions

Hello + loop

PRINT "Hello from QuickBASIC"
FOR i = 1 TO 5
  PRINT i
NEXT i

brainFOOD

A tiny programming language with only eight commands. It is great for learning how computers move data around and follow simple instructions. (This is the kid-friendly name for a classic minimalist language.)

The eight commands

  • > move right to the next box
  • < move left to the previous box
  • + add 1 to the number in the box
  • - subtract 1 from the number in the box
  • . show the character for the number in the box
  • , wait for the user to type a character
  • [ start a loop (repeat while the box is not zero)
  • ] end the loop

Hello World

++++++++++[>+++++++>++++++++++>+++>+<<<<-]>++.>+.+++++++..+++.>++.<<+++++++++++++++.>.+++.------.--------.>+.>.

Try changing numbers or adding commands to see what happens!

Delphi 5 / 6 / 7

Object Pascal RAD environment for Windows. Delphi 5–7 were the peak of classic VCL (Visual Component Library) development.

Key ideas

  • Units, forms, events (OnClick etc.)
  • VCL components (TButton, TEdit, TLabel…)
  • Strong typing, class, properties

Minimal form event

procedure TForm1.Button1Click(Sender: TObject);
begin
  ShowMessage('Hello from Delphi');
end;

INTERCAL

The original esoteric language (1972). Deliberately obtuse syntax and operators. Famous for the COME FROM statement.

Key ideas

  • Variables like .1, :1, ,1
  • Operators: mingle, select, unary ~
  • PLEASE politeness (too many or too few can be errors)

Notes

Full programs are verbose. Start by reading the INTERCAL Reference Manual and a short “Hello World” example from the C-INTERCAL distribution.

LOLCODE

Esolang based on lolcat-speak. Keywords are English phrases.

Key ideas

  • HAI / KTHXBYE program bounds
  • I HAS A variable, VISIBLE print
  • IM IN YR loops, O RLY? conditionals

Hello

HAI 1.2
VISIBLE "Hello from LOLCODE"
KTHXBYE

Malbolge

Named after the eighth circle of Hell. Designed to be nearly impossible to program. Instructions are encrypted and the code mutates as it runs.

Key ideas

  • Ternary (base-3) arithmetic
  • Self-modifying code
  • Almost no hand-written programs exist; most were generated

Notes

Practical learning focuses on reading the specification and examining known generated programs rather than writing new ones by hand.

Piet

Programs are images. Execution follows colored blocks (codels). Direction and stack operations are determined by color changes.

Key ideas

  • Hue and lightness encode operations
  • Direction pointer and codel chooser
  • Stack-based

Notes

Best studied with a visual editor or interpreter (e.g. npiet) and small example images. Text representation is not practical.

Whitespace

Only spaces, tabs, and newlines are significant. Everything else is ignored (comments).

Key ideas

  • Commands are sequences of whitespace
  • Stack and heap operations, I/O, flow control
  • Imperative, stack-based

Notes

Programs are invisible in normal editors. Use a dedicated Whitespace IDE or carefully constructed files. A common first exercise is a simple number printer.

Win16 programming

16-bit Windows (Windows 3.x era) programming. Classic API with WinMain, message loops, and resource files.

Key ideas

  • WinMain entry point
  • Window class registration, CreateWindow, message loop (GetMessage / DispatchMessage)
  • Window procedures (WndProc) handling WM_* messages
  • Often written in C with the Windows SDK or early Visual C++

Minimal skeleton (conceptual)

int PASCAL WinMain(HINSTANCE hInst, HINSTANCE hPrev, LPSTR cmd, int show) {
  // register class, create window, message loop
  return 0;
}

Modern compilers no longer target Win16. Study with old SDKs, books, or emulators (e.g. Windows 3.1 in DOSBox / 86Box).

Z80 Assembly

Assembly language for the Zilog Z80 CPU. Widely used in 1980s home computers (ZX Spectrum, MSX, TRS-80, CP/M machines) and still popular for retro and embedded work.

Key ideas

  • Registers: A, B, C, D, E, H, L, and pairs (BC, DE, HL)
  • Flags, stack, and memory addressing modes
  • Common instructions: LD, ADD, INC, DJNZ, CALL, RET
  • Interrupt modes and I/O ports

Minimal example (load and increment)

    LD   A, 5      ; load 5 into accumulator
    INC  A         ; A = 6
    LD   (HL), A   ; store A at address in HL
    RET

Great next step after learning how a CPU actually moves data. Pair with a Z80 emulator or assembler (e.g. z80asm, SjASMPlus).
