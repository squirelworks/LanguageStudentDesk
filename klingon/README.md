# tlhIngan Hol — Klingon Teacher

A simple, self-contained web app for learning the Klingon language with a focus on the **pIqaD** script (not just Latin romanization).

## Features

- Interactive pIqaD alphabet with sound descriptions and examples
- Core vocabulary list (script + romanization + meaning)
- Basic grammar notes (OVS word order, verb prefixes, common phrases)
- Script recognition quiz

## How to use

Open `index.html` in any modern browser. No build step or dependencies required.

This is part of the LanguageStudentDesk project.
