# Electronics Learner

Short lessons with worked examples, then a practice round that explains every
answer. Courses run from foundations (units and Ohm's law) through components,
circuits and digital, then practical build skills (soldering, PCB design) and
systems topics. Progress is saved in the browser.

**Safety:** soldering and mains lessons include warnings; this is learning
material, not a substitute for lab training or local electrical codes.

## Launch

```
electronics-learner/index.html
electronics-learner/index.html?lang=foundations
electronics-learner/index.html?lang=soldering#joints
```

## Files

- `index.html`, `app.js`, `sections.js` — the page
- `data/catalog.js` — courses and groups
- `data/<id>.js` — one course (`window.ELECTRONICS.<id>`)
