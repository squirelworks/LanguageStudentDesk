# Maths Edu-Training Helper

The menu is `www/index.html`. The Desk launcher opens this folder's `index.html`, which redirects there. The Math Learner stays in the repo and keeps the same relative links. The name stays Maths Edu-Training Helper.

The Android app that ships is the native build, package `com.squirelworks.mathseducationtraininghelper`. The release file is [`MathsEduTrainingHelper.apk`](https://github.com/squirelworks/LanguageStudentDesk/releases/latest/download/MathsEduTrainingHelper.apk), signed with the committed debug key. A test APK can be built by hand with the `SquirrelGo test APK` workflow, choosing `math-native`.

The old WebView shell is in `archive/webview/math/` and is not built. Its Play listing pack is `archive/webview/math/app/src/main/play/`.
